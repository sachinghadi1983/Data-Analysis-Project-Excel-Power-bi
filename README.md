# Data Analysis Project - Excel & Power BI

## Project Overview
This project analyzes sales data using Excel and Power BI.

## Tools Used
- Microsoft Excel
- Power BI

## Key Analysis
- State Wise Sales vs Profit
- City Wise Sales vs Profit
- Product Wise Sales vs Profit
- Monthly Sales Trends
- Product Performance Analysis

## Dashboard Features
- Interactive Filters
- KPI Cards
- Charts and Visualizations

## Key Insights
- Identified top performing products.
- Analyzed sales and profit trends.
- Compared regional performance.
